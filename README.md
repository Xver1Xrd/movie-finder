Совместный выбор фильмов с друзьями — свайпай «Да/Нет», как в Tinder, и узнай, какой фильм хочет посмотреть вся компания.

---

## Возможности

- **Соло-режим** — отбирай фильмы для себя: результат делится на «Понравились» и «Не понравились»
- **Мультиплеер-комнаты** — до 10 игроков, вход по коду или **по прямой ссылке** (имя — и сразу в комнату)
- **Голосование свайпом** — вправо «Да», влево «Нет» (или кнопками)
- **Мэтч-режим** — все сказали «Да» одному фильму → конфетти, вибрация и «Это мэтч!» у всех; хост может сразу завершить
- **Живой прогресс игроков** — видно, кто сколько проголосовал; комната завершается автоматически, когда досвайпали все
- **Финальный раунд** — при ничьей хост запускает дополнительный раунд только между финалистами
- **Где смотреть** — стриминги для победителя и в карточке фильма (данные TMDB/JustWatch)
- **Темы контента**: фильмы, сериалы, аниме (Jikan/MyAnimeList, с фильтрами типа и статуса), мультфильмы
- **Фильтры подборки**: годы, жанры, страны, рейтинг (6+/7+/8+), сортировка, количество (5–80)
- **Поиск конкретного фильма** — добавь «тот самый» фильм в подборку вручную
- **«Другая подборка»** — реролл выдачи по тем же фильтрам, если первая не зашла
- **Скрытие просмотренного** — фильмы из прошлых сессий можно исключить из выдачи
- **Лёгкие рекомендации** — любимые жанры (по прошлым «Да») всплывают в подборке выше
- **Детали фильма** — описание, жанры, рейтинг, трейлер (YouTube) и стриминги по кнопке ⓘ
- **Мои голоса** — пересмотри свои ответы и передумай до конца голосования
- **Результаты** — тир-лист по голосам «Да», кнопка «Поделиться» с красивой OG-картинкой победителя
- **Вотчлист и история** — мэтчи копятся в вотчлист с отметкой «посмотрено», прошлые сессии — на главной
- **PWA** — ставится на главный экран телефона как приложение
- **Realtime** — статусы игроков, голоса и мэтчи обновляются через Supabase без перезагрузки

## Как это работает

1. **Хост создаёт комнату** (или играет соло) и настраивает подборку: категория, годы, жанры, страны, рейтинг, сортировка, количество. Можно вручную добавить конкретные фильмы через поиск.
2. **Друзья заходят по коду или по ссылке** и жмут «Готов».
3. **Все свайпают** одни и те же фильмы в своём темпе — прогресс каждого виден остальным. Смена голоса разрешена («Мои голоса»).
4. **Мэтч** — когда фильм собрал «Да» от всех, у всех конфетти; хост может сразу завершить.
5. **Авто-финиш** — комната завершается сама, когда проголосовали все. При ничьей — финальный раунд между лидерами.
6. **Результаты** — победитель, «где смотреть», кнопка «Поделиться». Мэтчи попадают в вотчлист, сессия — в историю.

## Запуск локально

```bash
npm install
cp .env.local.example .env.local   # заполнить ключи
npm run dev
```

Переменные окружения:

| Переменная | Описание |
|-----------|----------|
| `NEXT_PUBLIC_SUPABASE_URL` | URL проекта Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Anon-ключ Supabase |
| `TMDB_API_KEY` | API-ключ TMDB (серверный, используется прокси `/api/tmdb`) |

Схема БД: выполнить `supabase/migrations/*.sql` по порядку в SQL Editor Supabase.
**Важно:** миграция `003` обязательна — без неё не работает финальный раунд при ничьей.

**Обязательно перед миграцией `006`:** включить Anonymous Sign-ins —
Supabase Dashboard → Authentication → Providers → Anonymous. Миграция 006
завязывает RLS-политики на `auth.uid()` анонимной сессии; без включённого
провайдера `signInAnonymously()` на клиенте будет падать, и создание комнат,
вход участников и голосование перестанут работать.

Миграции `005`, `007` и `009` используют `pg_cron` (автоочистка комнат,
анонимных пользователей и записей rate limit) — расширение недоступно на
Free tier Supabase. На бесплатном плане пропустите их и чистите эти данные
внешним cron.
